# Reflection on Student Management Project

During this project, I improved my coding skills by implementing file I/O with error handling, regular expressions for validation, and object-oriented programming principles including inheritance.

I learned the importance of separating concerns by modularizing validation functions and handling user input thoroughly. Adding unit tests helped ensure my program runs reliably and handles edge cases.

In future projects, I plan to integrate version control through regular git commits and provide a clear video walkthrough explaining technical challenges and design choices.

This project helped me gain confidence in combining many Python concepts into a working application.
